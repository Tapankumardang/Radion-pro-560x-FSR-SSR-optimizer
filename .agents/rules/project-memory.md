# Project Memory & Continuous Update Rule

When working in this workspace:
1. **Pre-check:** Always consult [`PROJECT_MEMORY.md`](file:///e:/apps/Graphic%20card%20improve/PROJECT_MEMORY.md) first to understand hardware dynamics, existing files, and past mistakes to avoid.
2. **Continuous Updates:** Every time you make any change (editing code, fixing a bug, compiling a binary, modifying scripts, or altering settings), you **MUST** update [`PROJECT_MEMORY.md`](file:///e:/apps/Graphic%20card%20improve/PROJECT_MEMORY.md) in the same turn or before completing the turn.
3. Record the exact change, date, rationale, affected files, and any new lessons learned.
